# Checklist Breve de Pruebas y Entrega

## 1) Checklist de pruebas mínimas
- [ ] Ejecuté al menos 3 casos de prueba funcionales.
- [ ] Probé al menos 2 escenarios de error.
- [ ] Registré resultados esperados y obtenidos.

## 2) Checklist de documentación
- [ ] Completé `docs/propuesta.md`.
- [ ] Completé `docs/caso_de_uso.md`.
- [ ] Revisé `docs/estructura_repositorio.md` y respeté el orden.
- [ ] Completé `docs/plan_de_pruebas.md`.

## 3) Checklist de ejecución
- [ ] `scripts/run.sh` se ejecuta sin errores de estructura.
- [ ] Existe `src/main.<ext>` según mi lenguaje elegido.
- [ ] El prototipo mínimo corre localmente (si fue implementado).

## 4) Checklist de entrega final
- [ ] Mi proyecto se mantuvo pequeño y viable.
- [ ] No usé frameworks, nube, Docker, bases de datos ni APIs externas.
- [ ] El repositorio está ordenado y entendible.
- [ ] La propuesta está lista para revisión en GitHub Classroom.
