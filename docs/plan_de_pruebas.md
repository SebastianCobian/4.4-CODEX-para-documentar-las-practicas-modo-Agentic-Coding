## 5) Pruebas mínimas por lenguaje
- **ARM64 Assembly:** ejecución básica, validación de salida esperada y caso de error simple.
- **C:** compilación correcta, ejecución con entrada válida y manejo de error mínimo.
- **Python:** ejecución del script, caso válido y caso inválido.
- **Bash:** permisos de ejecución, corrida normal y validación de parámetros.

> No se requieren frameworks de testing para esta actividad.

- La documentación clave está completa.

- Existen pruebas mínimas registradas con evidencia.
- El alcance se mantuvo pequeño y viable.
